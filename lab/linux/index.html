Lo que aprenderás

Comandos

La guía crecerá con cada juego: explicación sencilla, ejemplo y enlace a la misión donde se usa.

pwd

Muestra la carpeta en la que estás. Misión 1.

pwd
whoami

Indica con qué usuario estás trabajando.

whoami
ls

Lista archivos y carpetas. La opción -a incluye los ocultos (sus nombres empiezan por punto); -l muestra detalles.

ls -la
cd

Cambia a otra carpeta. Misión 2.

cd retos
cat

Muestra el contenido de un archivo. Misiones 3 y 4.

cat bienvenida.txt
find

Busca archivos o carpetas por nombre y otras condiciones. Misión 4.

find / -name "clave.txt"
su

Cambia al usuario indicado. La terminal pide su contraseña.

su aprendiz2
sed

Filtra o transforma texto; por ejemplo, muestra una línea concreta. Misión 5.

sed -n '2p' apuntes/registro.txt
grep

Busca palabras o patrones dentro del contenido de archivos. Misión 6.

grep "CLAVE" logs/accesos.log
2>/dev/null

Redirige los mensajes de error para que no aparezcan en la terminal; los resultados de la búsqueda siguen visibles.

find / -name "informe.txt" 2>/dev/null
unzip

Lista o extrae el contenido de un archivo ZIP.

unzip -l pistas.zipunzip pistas.zip -d pistas
ssh

Abre una sesión segura con otro equipo. En el juego, la conexión será a un servidor simulado.

ssh user@servidor-lab
id

Muestra tu identificador de usuario y los grupos a los que perteneces.

id
sudo

Ejecuta un comando con permisos de administrador, si tu cuenta está autorizada.

sudo -l
chmod

Cambia los permisos de un archivo. En 660, propietario y grupo pueden leer y escribir.

chmod 660 informe.txt
chown

Cambia el propietario o el grupo de un archivo.

sudo chown user:equipo informe.txt
