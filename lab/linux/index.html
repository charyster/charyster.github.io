Juego de fundamentos · 6 misiones

Aprende jugando

Un recorrido paso a paso para aprender a orientarte, moverte entre carpetas, leer archivos y cambiar de usuario. Completa cada misión para desbloquear la siguiente.

Misión 01 · Reconocimiento

¿Dónde estoy?

El usuario anterior dejó una pista en su carpeta de retos. Explora el sistema y localiza el archivo clave.txt. Cuando lo encuentres, lee su contenido.

Pista: puedes empezar mirando dónde estás y qué archivos tienes. Si necesitas ayuda, escribe help en la terminal.

Estado: misión sin completar.

terminal-charyster
Lo que aprenderás

Comandos

La guía crecerá con cada juego: explicación sencilla, ejemplo y enlace a la misión donde se usa.

pwd

Muestra la carpeta en la que estás. Misión 1.

pwd
whoami

Indica con qué usuario estás trabajando.

whoami
ls

Lista archivos y carpetas. Misiones 1 y 2.

ls -la
cd

Cambia a otra carpeta. Misión 2.

cd retos
cat

Muestra el contenido de un archivo. Misiones 3 y 4.

cat bienvenida.txt
find

Busca archivos o carpetas por nombre y otras condiciones. Misión 4.

find / -name "clave.txt"
su

Cambia al usuario indicado. La terminal pide su contraseña.

su aprendiz2
sed

Filtra o transforma texto; por ejemplo, muestra una línea concreta. Misión 5.

sed -n '2p' apuntes/registro.txt
grep

Busca palabras o patrones dentro del contenido de archivos. Misión 6.

grep "CLAVE" logs/accesos.log
